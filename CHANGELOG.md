# CS.Coder - Class Indicator

## v1.0.1

- Same as 1.0.0, now published automatically (CurseForge and GitHub Releases).

## v1.0.0

- First release: the official class icon and the class name above enemy players' nameplates.
- Works with the default nameplates and with nameplate addons (Plater, and others).
- Shapes: round, rounded square, square, hexagon, diamond, shield. Borders: soft frame, soft glow, flat, metal shine.
- Class name: full or short, font, size, color, outline, shadow, position, and a background (badge, plate or ribbon).
- PvP: healer mark, bigger icon and glow on your target, bigger icons for the classes you pick.
- Quick styles and visual pickers, live preview, test mode (`/ci test`), profiles with export / import.
- Shared CS.Coder minimap button.
- English, Português, Español, Deutsch, Français, Italiano.
